# The allowlist. 158 tools are registered; this cuts them to ~32.
#
# Not tidiness: every tool definition sits in the model's context on every
# turn, and the upstream README warns that 110+ "can be a lot of context".
# A coach carrying 158 tool schemas is slower and less accurate at picking
# the right one -- which is the "slow and not smart" complaint, reproduced
# in a new place.
#
# Rule for what stays: everything a triathlon coach could reasonably want.
# The first cut of this list kept 35 and was too aggressive -- it dropped
# body composition, sleep detail, stress, Body Battery and personal records
# to save context that turned out to cost 3K tokens in total.
